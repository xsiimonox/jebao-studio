# Jebao Studio 0.3.0

## Neues Studio-Erlebnis

- Nativeartige, ruhige Oberfläche mit klarer Apple-inspirierter Hierarchie.
- Großes Strömungs-Dashboard mit Live-Wellenbild und Verbindungsübersicht.
- Pumpenkarten mit großen, gut erreichbaren Bedienelementen für Leistung,
  Frequenz, Modus, Ein/Aus und Fütterungspause.
- Synchronisierte Gruppensteuerung im gleichen Bedienmuster.
- Angepasste Darstellung für Mobilgeräte und Desktop.

Die lokale Steuerung und alle vorhandenen Home-Assistant-Entitäten bleiben
unverändert erhalten.
