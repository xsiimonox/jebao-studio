# Jebao Studio 0.2.5

Gespeicherte Pumpen werden im Studio auch angezeigt, wenn für sie noch kein Laufzeitgerät gestartet werden konnte. Die Karte erklärt den Einrichtungsfehler und bietet keine aktiven Steuerungen an.

Das Panel bietet jetzt direkte Links zur Home-Assistant-Einrichtung für „Pumpen suchen / hinzufügen“ und zur Verwaltung bestehender Einträge. „Aktualisieren“ lädt weiterhin nur die Anzeige neu.

Die tatsächliche Netzwerkverbindung zu den Controllern muss auf der betroffenen Home-Assistant-Installation geprüft werden. Dieser Fix betrifft die verschwundenen Karten und den fehlenden Zugang zur Suche, nicht einen nachgewiesenen Fehler im Pumpenprotokoll.
