# Jebao Studio 0.2.0

Jebao Studio 0.2.0 gives the pump panel a redesigned, calmer everyday-control surface and adds persistent flow-pump groups.

## Highlights

- New Jebao Studio wave logo and marine visual design
- Dedicated group workspace for compatible flow pumps
- Persistent group names and members, stored locally in Home Assistant
- Group actions for on/off, feed mode, shared flow level and shared mode, applied only to compatible online entities
- Two-pump preview data and automated group-control tests

## Scope and safety

MLW Wi-Fi remains the focus. DMP Bluetooth stays diagnostic-only, and dosing support remains prepared but locked. Hardware validation is still required before relying on any automation around livestock.

See the [installation guide](installation.md), [compatibility notes](compatibility.md), and [Bluetooth/DMP notes](bluetooth.md).
